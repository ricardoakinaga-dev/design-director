# Worked handoff examples

These are compact examples of the output contract. They are design specifications, not claims that a live app or generated image was produced.

## Banner for a veterinary clinic

```text
Mode: Banner/hero
Thesis: calm, competent care expressed through a human-scale moment of trust.
Medium: raster photo/illustration for the scene; HTML/CSS for exact copy and CTA.
Must preserve: supplied logo, supplied claims, readable CTA, subject-safe crop.
Must avoid: invented medical promise, urgency, generic stock composition, text baked into the image.
Evidence: asset inspection, native-size copy check, contrast, 375/768/1440 crop review.
Limit: no brand guide or final copy supplied; identity fidelity remains pending.
```

## Existing dashboard refinement

```text
Mode: Existing project + dashboard audit
Owner: frontend-app-builder for implementation; data-visualization for chart semantics.
Preserve: current tokens, table semantics, filters, content, and workflow behavior.
Change: hierarchy, spacing rhythm, status roles, focus states, responsive table strategy.
Evidence: baseline/current screenshots, filter and keyboard trace, empty/error states,
fidelity ledger, and fresh read-only critic.
Stop: do not replace real metrics with invented values or turn the table into card decoration.
```

## Reference reconstruction

```text
Reference roles: screenshot = composition + typography evidence; product logo = identity lock.
First pass: inspect native dimensions and decompose canvas, grid, chrome, content, type, media, states.
Implementation: semantic HTML/CSS/components; raster only for raster content visible in the reference.
Acceptance: compare geometry, type, spacing, color, imagery, copy, and states; rerender after the largest gap.
```
