# Visual hierarchy

## The first-glance path

For each surface, state what a new user should notice first, second, and third. Check that scale, contrast, position, whitespace, and grouping agree with that sequence. If everything is emphasized, nothing is.

## Hierarchy tools

- **Scale:** reserve the largest type or object for the highest-value message.
- **Contrast:** use color, weight, size, and density to distinguish roles; do not rely on color alone.
- **Position:** use reading direction and stable anchors; avoid decorative centering that hides the action.
- **Proximity:** group label, value, control, and feedback that belong together.
- **Repetition:** make related objects feel related, but vary only where meaning changes.
- **Whitespace:** give important groups room and use density where comparison or monitoring benefits.
- **Depth:** use elevation or layering to clarify ownership and priority, not to decorate every box.

## Diagnose a weak screen

Hide imagery and inspect the structure. Then squint or reduce contrast to test grouping and scale. Finally read only headings, labels, and actions. If the workflow disappears at any step, fix structure before adding polish.

## Density is contextual

Marketing pages need a clear narrative rhythm. Operational dashboards need scan-friendly density and comparison. Mobile needs shorter paths and reachable controls. Do not apply “airy” or “minimal” as universal goals; choose density for the user's decision cost.

## Content is geometry

Copy length, table columns, error messages, and localization change layout. Design with realistic text and worst reasonable wrapping. Never fix hierarchy by hiding required content or shrinking type below a readable role.
