# Design principles

## Design is a product decision

Start with the user's job, context, and action. A visual decision is successful when it makes the right thing easier to notice, understand, trust, and do. Beauty is a multiplier for clarity, not a substitute for it.

## Four tests for every visible choice

1. **Meaning:** what does this communicate?
2. **Priority:** why does it have this scale, contrast, or position?
3. **Belonging:** how does it fit the brand and the surrounding system?
4. **Cost:** what does it ask of attention, performance, accessibility, or maintenance?

If a choice has no answer beyond “it looks cool,” remove it or give it a real job.

## Distinctiveness with discipline

Find specificity in the product: its audience, vocabulary, material, cultural context, workflow, or useful tension. Prefer one memorable point of view plus a calm supporting system over many loud effects. A distinctive interface still needs predictable states, readable type, stable affordances, and responsive behavior.

## Preserve before replacing

In an existing project, inventory the logo, type, tokens, components, content, routes, and known conventions. Preserve useful identity and behavior. A redesign is not permission to erase product truth or create a parallel system. Record changes as deltas so later implementation and review can distinguish intentional change from regression.

## Evidence changes the level of confidence

Use a brief to establish intent, a concept to establish direction, code to establish behavior, and a render to establish visual outcome. Be explicit about which layer is proven. If a browser, font, reference, or asset is missing, reduce the claim rather than filling the evidence gap with confidence.

## A practical definition of premium

Premium work has a visible hierarchy, intentional proportions, strong typographic rhythm, coherent material and image language, few but meaningful effects, complete interaction states, and a finish level appropriate to the audience. It is calm where the user needs to decide and expressive where the brand needs to be remembered.
