# Anti-patterns

Use this as a rejection checklist, not as a style preference list. A listed treatment can be valid only when the product, brand, reference, or user request gives it a concrete job.

- AI gradient overload
- Purple/blue cliché
- Indiscriminate glassmorphism
- Too many cards or card-in-card nesting
- Borders everywhere
- Inconsistent radii
- Exaggerated shadows
- Purposeless decoration
- Generic hero or illustration
- Badge overload
- Generic font chosen without inspection
- Weak or competing CTA
- Bad copy width or awkward wrapping
- Inconsistent icon family
- Over-centering that hides hierarchy
- Dashboard presented as a landing page
- Desktop squeezed into mobile
- Neon overuse
- Low information density where comparison is the job
- Fake metrics, testimonials, urgency, logos, or claims
- UI text baked into raster without a reason
- Approximate redraw of a supplied logo, product, face, or package
- Placeholder presented as approved final
- “Pixel-perfect” claimed without a reference, native screenshot, and comparison

## Repair order

Fix structure first: content, hierarchy, action, grid, type, and states. Then fix system consistency: tokens, components, icons, color roles, and responsive behavior. Only then tune finish: image crop, material, shadows, motion, and micro-spacing. Do not add another effect to conceal a structural miss.
