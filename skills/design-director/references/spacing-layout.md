# Spacing and layout

## Establish geometry

Define the container, maximum measure, page gutters, column/grid model, alignment anchors, and overflow behavior before styling components. Use a semantic spacing scale and a small set of layout primitives. Alignment should be explainable across sections.

## Rhythm over arbitrary gaps

Use related spacing for related relationships: label-to-control, control-to-control, group-to-group, and section-to-section. Larger gaps should communicate a change of idea. Avoid a different margin for every component; that makes refinement and responsive behavior unpredictable.

## Composition

Use asymmetry when it improves hierarchy, not as a novelty. Keep the primary action and important content within predictable visual anchors. Check crop, whitespace, and baseline alignment at the real content length. A decorative edge may cross a grid; it should not accidentally shift the product workflow.

## Cards and surfaces

Use a surface when it clarifies ownership, scan grouping, interaction, or depth. A card inside a card needs a distinct semantic reason. If borders, shadows, radii, and backgrounds all compete, remove the least informative layer.

## Responsive geometry

Change the composition when the content fails, not only at framework defaults. Define what collapses, reorders, scrolls, wraps, becomes a drawer, or is removed. Test intermediate widths; many layout bugs live between the named desktop and mobile endpoints.
