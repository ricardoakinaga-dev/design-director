# Typography

## Inspect before choosing

Inventory existing font files, licenses, weights, variable axes, fallbacks, and usage. Preserve an established brand type system unless change is authorized. Do not default to Inter or a generic system without a reason.

## Define roles, not isolated sizes

Specify display, heading, body, label, metadata, data, code, and button roles with family, weight, size, line-height, tracking, and measure. Use a small scale with semantic names and responsive steps. Keep controls and body copy optically aligned, not merely mathematically equal.

## Measure and wrapping

Set readable line lengths and test the longest realistic heading, label, error, and translated string. A good type choice fails if its measure produces walls of text, stranded words, or a CTA that changes height unpredictably. Keep exact user copy intact; change width, size, or hierarchy before rewriting it.

## Pairing and contrast

Pair type by role and voice. Contrast a display face with a neutral text face only when the difference improves recognition or tone. Check x-height, punctuation, numerals, and diacritics for the actual language. Use weight and spacing to establish hierarchy before adding color.

## Runtime checks

Verify fonts actually load, the fallback metrics do not shift critical layout, controls inherit the intended family, and variable-font settings are supported. Capture screenshots with the real font when visual parity matters; mark a substitute as a limitation rather than claiming exactness.
